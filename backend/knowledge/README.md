# Support content lifecycle

The eight entries are paraphrased general-support options grounded in linked source pages, checked on 2026-09-28. They are **not clinically reviewed**. The executable demo status is `source_checked_demo`; do not describe it as clinical approval.

Every entry records a stable ID, publisher, URL, tags, bounded text, audience/scope/exclusions, review date/due date, reviewer description and version. Update the source and review record together; preserve the prior baseline archive. Draft and expired entries are excluded. No runtime crawling or arbitrary model URLs are allowed.

Before a real-user release, a qualified reviewer must assess applicability to the intended users, limitations, regional crisis guidance and possible harms. Do not merely change clinical_reviewed to true. Record a real review and revisit the release gate.
